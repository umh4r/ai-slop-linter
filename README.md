# ai-slop-linter

日本語文書の校正用 lint ツール。

## 目的

日本語文書に含まれる、校正で指摘されやすい表現を機械的に検出する。

## 実装方針

- 実装言語：Python（3.12 以上）
- パッケージ管理：uv
- 形態素解析：SudachiPy（推奨として検討中。最終確定は未了）
  - 動作確認時の環境：SudachiPy 0.6.11、SudachiDict-core 20260723

## 検出要件（最低限）

1. ら抜き言葉（例：食べれない、見れる、来れる）
2. い抜き言葉（例：開発してます、遊んでる）
3. 特定の AI がよく使う単語（例：効く、正本）
4. 冗長表現（例：することができます）

## SudachiPy での判定方法

- ら抜き：辞書形が「正規化形の語幹＋れる」で、活用型が「下一段-ラ行」の動詞を検出する
  - 例：見れる → 辞書形「見れる」、正規化形「見る」、活用型「下一段-ラ行」
  - 「入れる」「流れる」は辞書形と正規化形が一致するため、上記条件に該当しない
- い抜き：助動詞「てる」（表層形「て」「でる」を含む）を検出する
- 冗長表現：トークン列「する＋こと＋が＋できる」を照合する
- 特定語：辞書形（例：「効い」→「効く」）で語彙リストと照合する

## 開発環境

VS Code の Dev Containers を使う場合は、リポジトリを開いて「Reopen in Container」を選ぶ。
コンテナ作成時に `uv sync --all-groups` が実行され、依存関係が `.venv` に導入される。

ローカルで直接使う場合は uv を導入した上で次を実行する。

```sh
uv sync --all-groups
```

## 使い方

```sh
uv run ai-slop-linter <対象ファイル>...
```
